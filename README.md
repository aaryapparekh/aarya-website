# aarya-website

A responsive Ember Noir personal website for Aarya Parekh, with an SVG A.P logo and a five-piece opening animation.

## Links

- [Dashboard](https://dashboard.aaryaparekh.com)
- [LinkedIn](https://www.linkedin.com/in/aarya-parag-parekh)

The production files are `index.html`, `ap-logo.svg`, `motion.css`, `viewport.css`, and `pump.js`. No build step is required; typography loads from Google Fonts.

The grid fills the dynamic viewport edge-to-edge. Panels and typography scale with available width and height, with a stacked composition for portrait windows.

Serve this directory with any static web server. Use `?motion-preview` to replay the opening animation. Reduced-motion preferences are respected, and the website remains usable without JavaScript.
